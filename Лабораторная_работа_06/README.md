# Лабораторная работа №6

Вариант 1: задания средней сложности 1, 3, 5.

## Файлы

- `task01_flask_hello_world.py` - Flask-приложение «Hello World».
- `task03_static_page_css.py` - статическая страница + CSS.
- `task05_bootstrap_page.py` - страница с Bootstrap.
- `templates/` - HTML-шаблоны.
- `static/style.css` - CSS.

## Запуск

```powershell
pip install flask
python task01_flask_hello_world.py
python task03_static_page_css.py
python task05_bootstrap_page.py
```

После запуска откройте адрес, указанный в консоли. Для удобства файлы используют порты `5001`, `5003` и `5005`.
